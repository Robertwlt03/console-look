# Changelog

All notable changes to this project are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-18

### Added

- Python module `console_look` with headings, result lines, notes, groups, tables, frames, a
  spinner, `wait` for commands and questions (yes or no, text, a list).
- `console-look` command to draw one piece at a time from make, shells and other languages.
- Swift package `ConsoleLook` with the same heading, result lines, notes and frame.
